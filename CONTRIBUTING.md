# Contributing to ORAKZAI GROUP Projects

Thank you for your interest in contributing to the ORAKZAI GROUP ecosystem.
We welcome contributions that improve our blockchain, AI, real estate, and
luxury commerce infrastructure.

## Getting Started

1. **Fork** the repository
2. **Clone** your fork locally
3. **Create a feature branch** from main
4. **Make your changes** following the style guide below
5. **Commit** with a clear message following our convention
6. **Push** your feature branch
7. **Open a Pull Request** using our PR template

## Commit Convention

We follow [Conventional Commits](https://www.conventionalcommits.org/):

| Prefix | When to use |
|--------|-------------|
| `feat:` | New feature |
| `fix:` | Bug fix |
| `docs:` | Documentation only |
| `refactor:` | Code restructuring |
| `test:` | Adding or updating tests |
| `chore:` | Build process, dependencies |
| `security:` | Security improvements |

## Code Style

- **TypeScript**: Strict mode, no `any`, ESLint + Prettier
- **Solidity**: Follow OpenZeppelin patterns, NatSpec comments
- **Python**: PEP 8, type hints required
- **All**: Self-documenting code preferred over inline comments

## Pull Request Guidelines

- One feature or fix per PR
- Include tests where applicable
- Update documentation if behavior changes
- Link related issues in the PR description

## Smart Contract Contributions

Smart contract changes require:
- Unit tests with more than 90% coverage
- Gas optimization notes
- Security consideration notes

## Reporting Issues

Use our issue templates:
- Bug Report
- Feature Request
- Question

## Community Standards

Please read our [Code of Conduct](CODE_OF_CONDUCT.md) before contributing.
